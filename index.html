How to Use the Calculator

This is a calculator that emulates the way in which an FPGA does math. It works with the five following data types: real, hexadecimal, 2's complement binary, IEEE-754 single and IEEE-754 double. It performs the following math operations: addition, subtraction, multiplication, division and modulo. It performs the following logic operations: AND, OR, XOR, NOT and 2's complement. This calculator can also be used to convert from one data type to another. Operations requiring two operands are entered as follows: operand1 operator operand2 (no spaces). Operations requiring one operand are entered as follows: operator operand (no spaces). The logic operations using the following operators: & = AND, | = OR, ^ = XOR, ~ = NOT, ! = 2's complement. All operands are converted to binary before performing any math or logic operations. The results are then converted from binary to the selected output type. There is no need for 0x or 0b for hex and binary values. The integer size and fraction size values are used for hexadecimal entry and for the results of divisions. Binary values can include a binary point.
